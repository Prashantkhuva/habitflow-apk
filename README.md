# habitflow-apk

HabitFlow Android APK release assets. No source code lives here.

- Latest APK (always newest): <https://github.com/Prashantkhuva/habitflow-apk/releases/latest/download/HabitFlow.apk>
- Releases are created automatically by the main repo's tag-driven release workflow: it commits the built APK + annotated tag here, this repo's workflow turns the tag into a GitHub release.
- Download page: <https://habitflow.indevs.in/download>
